## Detailed findings

### [P1] Mobile “More” label fails text contrast
- **Location:** `Header.tsx` — `text-[10px] … text-cream/45`
- **Category:** Accessibility
- **Impact:** Effective contrast on `#1B3F24` ≈ **3.55:1** (needs ≥4.5:1 for normal text). Small uppercase eyebrow is still text.
- **WCAG:** 1.4.3 Contrast (Minimum)
- **Fix direction:** `text-cream/70`+ (≈6.3:1) or gold-bright; bump to `text-xs`.
- **Suggested command:** `$impeccable harden` / `$impeccable typeset`

### [P1] Scroll lock can stick when resizing to desktop with menu open
- **Location:** `Header.tsx` — `open` + `body.style.overflow`; dialog is `lg:hidden`
- **Category:** Accessibility / Responsive
- **Impact:** Open menu, widen past `lg`: panel hides via CSS but `open` stays true → page cannot scroll until refresh or toggle somehow.
- **Fix direction:** On `resize` / `matchMedia('(min-width: 1024px)')`, if matches then `setOpen(false)`.
- **Suggested command:** `$impeccable adapt` / `$impeccable harden`

### [P2] Background not inert while menu open
- **Location:** Dialog vs `#main` / header underlay
- **Category:** Accessibility
- **Impact:** Keyboard trap is good; SR users may still roam the page behind `aria-modal` in some AT.
- **Fix direction:** `inert` on `main` (and optionally the top bar) while `open`, or `aria-hidden` on siblings.
- **Suggested command:** `$impeccable harden`

### [P2] Desktop / tablet link targets under 44px
- **Location:** `.nav-link` `min-height: 2.5rem` (40px); “Book a Taster” `min-h-10`; Logo mark `h-9` (36px) though link is `min-h-10`
- **Category:** Responsive / Touch
- **Impact:** Fine for mouse; landscape tablets at `lg` get the tray with 40px hits.
- **Fix direction:** `min-h-11` on `.nav-link` and Book a Taster; keep visual padding balanced.
- **Suggested command:** `$impeccable adapt`

### [P2] Logo wordmark type too small for sighted users
- **Location:** `Logo.tsx` — “Global Echoes” `11px`, “Ireland” `8.5px`
- **Category:** Accessibility / Typography
- **Impact:** SR gets full `aria-label` (OK). Sighted users, especially older commissioners, struggle with 8.5px.
- **Fix direction:** Title ≥12px; subtitle ≥10–11px; or single-line lockup.
- **Suggested command:** `$impeccable typeset`

### [P2] Stale “8 links” density CSS
- **Location:** `styles.css` `@media (lg–xl)` shrinks `.nav-link` further
- **Category:** Implementation Integrity / Responsive
- **Impact:** Only 5 links now; squeeze is unnecessary and worsens touch/type.
- **Fix direction:** Remove or relax the 1024–1279 compression block.
- **Suggested command:** `$impeccable distill` / `$impeccable adapt`

### [P3] Hard-coded nav colors vs tokens
- **Location:** `.nav-link { color: #2d2d2d }`; `.nav-glass-dark` `rgba(9,28,16,…)`
- **Category:** Theming
- **Impact:** Close to ink / forest-deep; harder to restyle.
- **Fix direction:** `var(--ink)` / `color-mix` with `--forest-deep`.
- **Suggested command:** `$impeccable polish`

### [P3] Hero-past threshold is viewport heuristic
- **Location:** `scrollY > innerHeight - 80`
- **Category:** Implementation Integrity
- **Impact:** Works while home hero is `min-h-dvh`; drifts if hero height changes.
- **Fix direction:** Observe masthead `IntersectionObserver` / `ResizeObserver`.
- **Suggested command:** `$impeccable harden`

### [P3] Heavy liquid-glass blur
- **Location:** `.nav-glass` `blur(22px) saturate(1.55)`
- **Category:** Performance
- **Impact:** Cinematic; can jank on low-end while scrolling under fixed header.
- **Fix direction:** Cap blur ~12–16px; keep reduced-transparency solid path.
- **Suggested command:** `$impeccable optimize`

### [P3] Detector false quiet
- Static detector found **0** issues — does not clear contrast, scroll-lock, or touch targets.
