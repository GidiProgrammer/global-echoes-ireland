## Design Specificity Verdict

**LLM assessment:** The full-bleed drumming hero is product-specific (session imagery, forest scrim, gold italic “Rhythm,” Book a Taster). Most interior sections are category-interchangeable nonprofit template: Lucide-in-circle rows, 3/4 equal columns, circular founder avatars, bordered strategy cards. An unrelated wellness org could wear the shell with a palette swap.

**Deterministic scan:** `detect.mjs --json src/routes src/components/site` exited **0** with **0 findings** (empty `[]`). Sanity check on a known-bad Inter/purple fixture still fires rules — empty result is real for static mode. Detector does **not** cover contrast ratios, faux logos, mailto UX, or Framer Motion gaps; those came from file-backed technical review. URL scan skipped (Puppeteer required).

**Visual overlays:** No reliable user-visible overlay — browser mutation / Puppeteer unavailable this session. Curl smoke: `/`, `/about`, `/blog`, `/contact`, `/funders`, `/og-image.jpg` all 200.

## Overall Impression

The first viewport earns attention; the rest of the site spends it. Biggest opportunity: **re-lock the brand system to the board** and **shorten the Persuade path** so Programme → Services → Contact is unmistakable, with trust elements that don’t overclaim.

## What's Working

1. **Home masthead** — full-bleed session photo, layered scrim/grain, bottom-anchored display type, clear primary/secondary CTAs.
2. **Honest Persuade copy** — no fabricated testimonials; clinical + cultural framing; gallery admits stock where needed.
3. **Chrome a11y baseline** — skip link, focus rings, mobile focus trap/Escape, active nav, reduced-transparency / reduced-motion paths (partial).

## Priority Issues

### [P0] Brand system not shipped (tokens + fonts drift from board)
- **Why it matters:** MASTER.md and the inspiration board require Instrument Serif + forest `#1B3F24` / gold `#B8860B` / maroon `#70201F`. Live code uses Cormorant Garamond + `#1a6b3c` / `#c89b2a` / `#8b1a1a`. Motto “Rhythm as Medicine” never appears in `src`. Brand inconsistency undermines healthcare credibility.
- **Fix:** Lock `styles.css` + `__root.tsx` fonts/hexes to the board; introduce the motto as a recurring verbal beat; update `pages/home.md` to match the cinematic hero (or revert layout to documented split-circle).
- **Suggested command:** `$impeccable document` then `$impeccable typeset` / `$impeccable colorize`

### [P0] Trust fractures (faux partners, legal stubs, thin proof)
- **Why it matters:** Care-home managers and HSE funders treat “Working with” as partnership claims. Privacy/Terms as non-links and a LinkedIn search URL look unfinished. Blog “Coming soon” and stock gallery weaken social proof after a strong hero.
- **Fix:** Relabel partner strip as strategy alignment **or** use real logo assets with accurate claims; real Privacy/Terms pages or remove; fix LinkedIn; demote Blog/Gallery until content-ready.
- **Suggested command:** `$impeccable clarify` + `$impeccable harden`

### [P1] Interior sameness + nav overload
- **Why it matters:** Eight primary nav items and repeated Lucide 3/4-up grids create cognitive load; programme length and services pricing aren’t on one path.
- **Fix:** Collapse nav to ≤5 (About, Programme, Services, For Funders, Contact); rebuild interiors as asymmetric story layouts with one recommended duration + CTA; merge duplicate home Benefits vs `/programme`.
- **Suggested command:** `$impeccable distill` then `$impeccable layout`

### [P1] Conversion friction on Contact / Programme
- **Why it matters:** Institutional bookers need a reliable request path. Mailto after “Sending…” is ambiguous; free-text Interest invites vague enquiries; programme option cards lack CTAs.
- **Fix:** Real submit endpoint or honest “opens your email app” + copy-to-clipboard; Interest as `<select>`; programme cards → `/contact` with prefilled interest; associate Message label (`htmlFor`/`id`); `aria-live` on errors.
- **Suggested command:** `$impeccable harden` + `$impeccable clarify`

### [P2] A11y / motion / perf gaps the detector missed
- **Why it matters:** Gold-on-cream eyebrows fail AA (~2.41:1); hero `motion.*` blocks ignore `useReducedMotion`; 402KB hero + Google Fonts CSS cost LCP.
- **Fix:** Use `gold-ink` for cream contexts; gate all Framer heroes with reduced motion; compress hero image / self-host fonts; strengthen contact focus rings.
- **Suggested command:** `$impeccable audit` follow-up → `$impeccable optimize` + `$impeccable polish`

## Persona Red Flags

**Care-home manager (Jordan / first-timer institutional buyer):** Can’t see cost + duration + book on one path; 8-nav + long home scroll before clarity; mailto undermines “reply within one working day.”

**HSE funder (Alex / evidence-seeking):** “Working with” marks look like endorsements; Programme Profile is request-only with no PDF asset; six equal Landmark cards feel thin for a board pack.

**Family member / community visitor:** Stock gallery + no resident/family voice after the hero; clinical credentials dominate lived warmth mid-page.

## Minor Observations

- Hero copy uses an em-dash (MASTER anti-pattern).
- `pages/home.md` still describes split-circle + trust-in-viewport; code is full-bleed cinematic.
